# 班级日报验收 · 2026-10-28

新增按班级、日期保存的班级日报。教师从工作台的“班级日报”进入当前班级，后台与App也可从全部功能进入；小程序新增同名页面。

## 页面与保存规则

自动展示所选班级的学生人数、已到校人数（含已离校）、已请假人数和作业完成份数。概况从所选日期现有业务记录计算；正文由老师填写，包含必填“班级日报”（最多6000字）、可选“需跟进事项”和“后续安排”（分别最多2000字）。日报显示记录人、最近更新人及更新时间，支持按日期回看、编辑。

同班同日只有一份日报，重复请求内容相同时不新增记录或版本；编辑带原版本，其他人更新后返回409，界面保留未保存内容供核对。未来日期不能保存已发生情况。记录人与时间由服务端确定，客户端不能指定作者。

## 权限

教师仅可读写当前授权班级；同校区的其他班级也不可访问。校长仅可读写授权校区内的班级，老板可查看和维护全部校区。家长不能访问班级日报接口，页面与导航也不向家长提供班级日报入口。机构内部的班级记录与已有个人成长小结分别存储。

接口为`GET /api/class-reports?classId=&date=`与`PUT /api/class-reports/{classId}?date=`，保存字段`{content,followUp,nextPlan,expectedVersion}`。`classId`省略时选择第一个授权班级；没有授权班级返回空页面。V14新增`class_daily_report`表，不替换原有个人小结。修改写入校区审计，审计仅记录班级、日期与日报ID。
