## 新增流程与关键字段

- 请假：学生、日期、原因、申请人/时间、状态、审核人/意见、版本、处理日志。状态为 `REQUESTED → APPROVED / REJECTED`，待审核/已批准可撤销为 `CANCELLED`；历史及已到校学生不允许整日请假。
- 接送：孩子、授权监护人、接送人姓名/关系/电话、同一天有效期、状态、版本、核验老师/有效期/使用时间、交接日志。状态为 `ACTIVE → USED / REVOKED`，过期显示 `EXPIRED`；接送码仅创建/重置响应显示一次，不写页面持久草稿，隐藏或切换身份清理。重置与解绑使旧核验失效。
- 退款：原续费单、金额（分）、退回购买/赠送课时、原因、申请/审核/确认人、版本、实际退款方式、流水号/签收凭证、退款课时流水与历史。状态为 `REQUESTED → APPROVED / REJECTED / CANCELLED`，`APPROVED → CONFIRMED / CANCELLED`。批准尚未退款，不能显示为已退款。
- 日报审核：正文、评语、版本、提交人/时间、审核人/时间/意见、审核版本、快照与审核历史；正文上限12000字。状态为 `DRAFT / REJECTED → IN_REVIEW → APPROVED / REJECTED → PUBLISHED`；撤回回到草稿。
- 隐私：当前政策版本、孩子、SERVICE/MEDIA选择与历史、EXPORT/ERASURE申请、审核及执行记录。解绑家长仅保留本人请求类型/状态/时间回执，不获得孩子新姓名、意见或导出内容。
