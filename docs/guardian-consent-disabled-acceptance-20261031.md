# 家长单独授权关闭验收（2026-10-31）

当前默认关闭家长对孩子SERVICE/MEDIA的单独授权要求。头像、作业图片、录音、视频与拍照识题按原账号绑定、任教班级和校区范围直接使用，无需逐个孩子补授权。页面隐藏同意/撤回操作，“隐私与数据”保留资料说明、资料副本申请和脱敏流程。

## 实现与边界

- 使用统一配置`app.privacy.consent-required`，由`GUARDIAN_CONSENT_REQUIRED`设置，默认`false`；当前18080和隔离预览18085均已以关闭模式启动。
- 统一媒体校验在关闭模式不再依赖授权记录；`consentRequired=false`、`canConsent=false`，业务有效状态为可用。原始同意/撤回状态和历史如实保留，不自动补写同意，不删除记录。
- 绑定家长向停用的授权写接口提交会返回410；跨孩子或错误角色仍403。
- 登录、家长与孩子绑定、老师班级范围、校区范围、文件票据、被阻断附件、已脱敏孩子和资料申请审核继续校验。接送人授权及到校/离校核验不受此开关影响。
- 如需恢复该流程，可将环境变量设为`true`后重启后端；原授权规则及历史记录仍在。
