## 状态流转

- 作业：未开始 → 进行中 → 待批改 → 需订正 → 待复核 → 已完成。老师现场检查可直接确认完成。订正必须有文字说明或尚未关联该作业的新附件；复用旧附件不能充当新的订正证据。完成奖励依照现有后端规则只入账一次。
- 关注事项：待跟进 → 处理中 → 已解决。已解决可带原因重开为处理中；创建人或授权管理员可将待跟进/处理中事项带原因撤销。历史记录追加保存。
- 家长回应：已了解、补充反馈、已配合待核实；这些操作均不自动解决事项。普通留言不计入关注数量。
- 体能：真实参与记录、因故暂停、尚未记录分别展示；暂停需要原因和措施，本身不扣分、不自动生成关注事项。
- 日报：草稿按当前业务数据汇总，发布时保留不可变快照。有未解决关注事项时，须逐个学生核对原因和措施后确认。尚未完成作业可如实发布。

作业归属日期与实际处理日期分开：旧日期作业继续处理后，详情显示「含后续处理」，时间轴和积分依据实际发生/入账日期。老数据缺少具体时间时显示「当日记录 / 具体时间未记录」。未来日期只展示安排，服务器拒绝登记未来已发生事实。
