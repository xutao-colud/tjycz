# 多校区权限验收

## 实施范围

总管理员可查看全部校区及各校区老师、学生与业务数据。校区校长仅管理授权校区，教师按授权班级、家长按绑定孩子访问。账号的校区管理范围由总管理员配置，修改后现有登录会话按最新授权校验。

角色：SUPER_ADMIN（总管理员）、ADMIN（校区校长）、TEACHER、PARENT。

校区选择通过X-Campus-Id作为请求筛选条件，后端同时检查登录人的校区范围；传入其他校区ID不会扩大权限。课时账户、作业、错题、日报、签到、积分和附件均继承学生所在校区。

## 迁移保护

历史ADMIN升级为总管理员，旧数据归入默认校区。旧班级、学生、课时账户、流水及上传文件保留。通过Flyway新增迁移完成，不修改已执行的迁移脚本。

迁移前保存了不含登录凭据的本地核对快照：10位学生、12个课时账户、18条课时流水、2个音视频附件，用于升级后确认原数据与余额未变。

## 独立业务验收入口

```bash
python3 scripts/campus_smoke.py
```

仅可在local演示环境执行，会创建标记“校区验收”的两个独立校区及虚构账号，不修改原学生。覆盖总管理员跨校区/单校区视图，校长列表及直接ID隔离，伪造校区请求头拒绝，混合批量操作拒绝，报名排课校区一致性，续费/冲正/补扣越权拒绝，账号授权防提权，修改授权即时生效，以及语音附件读取和挂接隔离。

## 操作入口

后台顶部或侧栏校区选择器切换授权范围；校区管理查看校区及师生统计；成员与权限中创建校长、分配校区或调整教师班级与家长孩子绑定。校长不能授予自身其他校区，不能创建总管理员或修改机构全局配置。

小程序识别总管理员和校区校长身份，显示可访问校区，数据仍由后端检查；两个开发目录保留各自环境配置，相关角色与页面修改定向同步。
