# 首版实现与验收记录

验收日期：2026-10-27。代码交付位于当前项目目录。本记录区分已经运行的功能、自动验证范围和仍需配置/人工验收的能力。

## 已实现

- Java 17 / Spring Boot 3 后端，模块化业务服务、JDBC事务、Flyway V1–V3迁移。
- Vue 3 / TypeScript 管理后台，11个导航入口，真实接口、加载/空数据/错误、表单校验与操作确认。
- 微信原生小程序，12个页面、5个共享组件，教师/家长身份、图片视频及MP3录音附件。
- 学生建档、建班、建课程、教师与家长账号创建及数据库授权关系。

- 作业批量分配、提交、批改、订正、复核及附件关联。
- 教师/家长错题录入、订正记录、教师复核、创建后第1/3/7天复习任务。
- 体能打卡、按事件防重的积分流水、机构可配置奖励规则。
- 各课程独立课时账户、购买/赠送/消耗流水、原流水关联冲正。
- 线下续费登记、确认入账、低余额提醒与操作日志。
- 日小结草稿、教师评语、发布时刷新汇总并保存快照、家长评分反馈。
- 本地H2文件持久化、MySQL生产配置、Dockerfiles与Compose。

## 独立本地业务验收

命令：`python3 scripts/smoke.py`。

结果：**全部通过**。使用独立验收班级、学生与课程验证：

1. 家长/教师越权访问被拒绝。
2. 购买10次、赠送2次，并发确认后余额为12次。
3. 重复签到/签退后只消耗1次，冲正后恢复12次，再次冲正不增加余额。
4. 作业从开始、提交、退回订正、待复核到完成，完成奖励仅一次。
5. 错题订正复核后生成3个复习任务；体能重复提交不重复奖励。
6. 日小结生成、评语、发布成功；通知未配置时明确返回NOT_CONFIGURED。

首次运行在作业查询处发现500错误，修复事务代理字段访问后完整回归通过。

初始演示数据为8名虚构学生、2个班级。当前本地持久化库另保留独立验收数据，因此管理后台总人数可能大于8。标记“集成验收”的班级、学生与课程可用于核对账目。“小程序接口联调”记录是小程序测试生成，均为虚构数据。早期联调还留下2条2026-11-10测试作业；没有对应的未来签到或消课。

## 真实MySQL生产配置验收

使用独立 MySQL **8.4.11** 容器和独立测试库，prod后端使用18081端口，未触碰已有其他项目数据库。

Flyway **V1、V2、V3迁移全部成功**，包含最终账户等式约束。

命令：设置测试管理员凭据后运行 `python3 scripts/prod_smoke.py`。

结果：**全部通过**：

- 生产禁用演示登录，默认演示账号不能登录，匿名业务访问返回401。
- 空库创建班级、学生、课程、教师/家长账号，并持久化访问范围。
- 教师不能创建课程，家长/教师不能读取未授权学生。
- 余额不足仍可登记离校，创建PENDING消课。
- 并发确认购买4次+赠送1次仅入账一次，补扣后余额4次，重复补扣不再扣减。
- 家长不可读草稿；发布后可读并反馈5分；教师不能覆盖已发布评语。
- 同一积分requestId重试幂等，不同内容复用requestId返回409。

验收结束后，临时prod服务和MySQL容器已停止；本地H2后端与Web仍运行。
