# 印刷题干与标题自动填充验收（2026-10-31）

拍照识题现在自动填入印刷题干、标题、选项和表格文字；老师可以校对标题及正文，再勾选入库。标题复用`groupName`，正文复用`questionText`，导入后沿用校对标题作为错题条目的标题；通用占位标题仍回退为题号。没有新增数据库字段。旧扫描任务、校对和已入库错题保持原状，使用“原图重识别”创建带自动文字的新任务。

## 实现

- 保留本机现有PaddleOCR模型及方向、版面、检测流程。按行高及长宽比例筛选常规印刷行，读取整行，排除明显的大字手写和独立答题演算行；不再清空识别正文。
- 标题优先使用印刷章节标题；否则提取题干首行并去题号，最多160字。OCR把题号与正文数量连读时，在已确认题号处补回分隔空格。
- 相似长宽比的文字行使用4行一批识别，减少批内填充。标准页仍保留最长边2600像素；检测最长边1280像素。图示、公式与原有笔迹仍保存在裁图中。
- 小程序自动填入“题目标题”和“印刷题干”，两者均可编辑；仍只导入老师明确勾选的题目。

## 原图实测

同一张用户提供的练习页，修改前文字为空；修改后仍分为第3题、第4题、附加题，三题正文均非空。第4题自动标题为“3位家长带6名儿童去公园划船，怎样买票最划算？”，正文包含该题干及划船价目表、成人票、儿童票和团体票文字；附加题正文包含纸盒问题与图中说明。抽查本页手写计算及答句未混入结果，原图笔迹未擦除。

同机内部OCR接口3次耗时为8.18、5.23、5.34秒，中位约5.34秒；首轮推理较慢。该版本包含整行印刷文字识别，测量不含手机上传、任务排队及页面轮询，不能视为其他图片的耗时保证。

## 限制

当前过滤基于版面和行尺寸，不是可靠区分所有印刷/手写的专用分类模型。混写或覆盖处可能漏掉部分印刷文字，小字手写也可能误入；字号特殊、短图注、严重斜拍和复杂版式需人工校对。原图与裁图用于保留这些内容，不编造缺失题干。未进行微信真机复测。
