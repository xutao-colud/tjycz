# 接送管理原型开发与验收记录

日期：2026-10-28。基于既有原生微信小程序、Vue 后台与 Spring Boot 服务实施，保留上一轮业务流程及数据。

## 交付行为

| 原型能力 | 本轮实现与验收口径 |
| --- | --- |
| 成长页接送入口 | 在托管状态、当日排课预计结束时间、常用/计划接送人和接送管理入口；未知排课时间不编造 19:00 |
| 常用接送人 | 当前绑定监护人可新增、编辑、删除、设默认；教师只读且电话脱敏；默认人不自动获得接送权 |
| 临时接送三步 | 填写信息 → 人脸核验 → 确认授权，含常用人复用、单次/多次、日期区间、每日时段、备注和确认勾选 |
| 身份证移除 | 无身份证照片、号码、上传或校验界面；后端拒绝在联系人/授权请求中夹带身份证字段 |
| 人脸保留 | `PICKUP_FACE_PROVIDER` 留空；状态真实为 `NOT_CONFIGURED`、禁止采集；核验接口返回 503，不保存照片、不生成核验通过记录 |
| 现场替代流程 | 用户明确选择先登记；到校后教师核对姓名、电话后四位、六位码和现场身份，再单独确认实际离校 |
| 成功与分享 | 成功后显示六位码；码不在普通查询中返回，创建/重置仅显示一次；通过用户主动复制或可用的系统分享传递 |
| 有效/历史与撤销 | 有效、使用、过期、撤销状态分组；撤销需确认与原因，旧码及旧核验立即失效并保留历史 |
| 教师异常 | 未授权等现场异常登记，OPEN/HOLD/RESOLVED与操作日志；工作台显示站内提醒，可联系家长、暂不离校与记录处理结果 |
| 原型样式 | 统一柔和背景、圆角卡片、选择器/输入框、蓝色主按钮、浅红异常、三步进度；成长/作业页增加语义色和浅色反馈/订正区 |

人脸目前仅保留步骤、真实状态和接口边界。后续提供供应商配置后仍需实现供应商适配、凭证处理与真实设备核验，不是填入一个名称即可识别。当前没有生物识别验收结论。

## 服务端状态与门禁

- `SINGLE`：同日指定时段使用一次后转为 USED。
- `MULTI`：日期区间内每日指定时段一次，使用后保留 ACTIVE；当天不能重复交接，第二天必须重新核验，旧核验不能跨午夜复用。
- 创建授权检测日期区间与每日时段的重叠；联系人版本变化返回 409，防止以旧资料确认授权。
- 编辑/删除常用人或解绑监护人，使相关有效授权或核验失效。设默认只修改偏好。
- 核验绑定当前教师、授权版本与当天，10 分钟有效；5 次错误接送码锁定 15 分钟。
- 告警 OPEN/HOLD 拦截实际离校并废止旧核验；RESOLVED 只解除该项异常，不能替代有效授权与重新核验。
- 成功核验只清除同授权、同日的自动 OPEN 告警，不清除人工告警、HOLD 或其他授权的告警。
- 签退事务检查当前权限、绑定、时段、当天核验和告警；学生锁与使用记录唯一约束防止并发重复交接/课时扣减。
- 私有头像沿用媒体授权与受控文件访问；导出/脱敏包含新联系人与告警记录，未处理异常须先完成处置。
