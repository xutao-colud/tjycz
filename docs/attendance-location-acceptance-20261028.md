# 校区范围定位签到验收 · 2026-10-28

已实现校区地址范围设置、学生到校定位签到及老师本人定位签到，后台、App与小程序使用同一服务端规则。

## 使用方式

管理员在“校区管理 → 设置签到范围”填写签到地址、中心点与半径。可在校区现场点击“使用当前位置”，或填写WGS84经纬度；半径提供50、100、200、300、500、1000、2000、3000米选项。校长只管理授权校区，总管理员管理全部校区。

到校签到页选择已配置地址，页面筛出对应校区学生。确认后获取新位置，服务端核对学生归属与当前校区配置；老师签到复用同一规则。未配置、拒绝/缺少定位、超范围、精度超过半径或定位超过120秒均不登记。服务端拒绝未来超过30秒的位置时间；不允许客户端修改打卡人、服务端签到时间或用另一个校区的配置代替。

校区配置通过V13增量迁移新增可空字段，不替换历史考勤；签到来源记为`LOCATION`。请求中的签到者位置仅用于当次核验，不落库、不写入审计详情；审计保留配置修改的操作者、校区与半径。客户端定位仍可能受到系统精度或伪造位置影响，本次没有实现设备位置防伪。
