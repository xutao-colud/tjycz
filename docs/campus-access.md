# 校区权限实施约定

用户要求：总管理员查看全部校区及老师、学生；校区校长仅管理授权校区。管理员可以配置每人不同校区范围。校区限制在后端执行，查询和写操作均生效。

## 角色

- `SUPER_ADMIN` 总管理员：全局管理、校区创建、校区管理员授权，可查看所有校区的老师学生与业务。
- `ADMIN` 校区管理员/校长：仅授权 `campusIds` 中的校区；可创建本校区班级、课程、学生、教师/家长，不能创建总管理员/校区管理员、不能自行扩权。
- `TEACHER` 教师：已授权班级，且可选择对应校区；禁止访问其他校区/班级。
- `PARENT` 家长：绑定孩子，不受前端传入学生ID影响；绑定可以覆盖不同校区的孩子。

已有全局ADMIN迁移为SUPER_ADMIN。历史业务数据迁移到默认校区，数据不可删除/清空。演示管理员入口仍传ADMIN但返回真实SUPER_ADMIN；新增CAMPUS_ADMIN演示入口可返回ADMIN，至少两个校区可验证。production环境变量初始化SUPER_ADMIN。

## 校区上下文

请求头 `X-Campus-Id: <id>` 为可选筛选，只能缩小当前用户的授权范围，不能扩大。

- 总管理员无header：全部校区汇总；有header：指定校区。
- 校区管理员无header：全部已授权校区；有header：必须是授权校区。
- 教师/家长：在原有班级/孩子权限基础上继续按校区缩小。
- 无权校区header或写入未授权校区返回403。

班级/课程明确 `campusId`；学生、作业、积分、账本、续费、日报、附件通过班级/学生归属继承。报名排课必须校区一致。后台新增班级/课程时必须选择具体可管理校区，单校区可自动选中。老师管理列表只展示能管理的老师/家长，不显示其他校区个人资料。

## 新增/扩展接口

- `GET /campuses` → `[{id,name,address,enabled,studentCount,teacherCount,classCount}]` 仅返回可访问校区。
- `POST /campuses` `{name,address}` → 校区，仅SUPER_ADMIN。
- `GET /me` / 登录user扩展 `{isSuperAdmin:boolean,campusIds:number[],campuses:[{id,name}],...}`，role依实际身份返回。
- `GET /users` 返回安全范围内账号，扩展 `{campusIds,campusNames,classIds,studentIds}`；SUPER_ADMIN可看所有，校区ADMIN仅自己校区及其可管理账号，不可见其他校区隐私。
- `POST /users` 沿用RSA加密密码和一次性challenge；新增可创建ADMIN（仅SUPER_ADMIN），ADMIN传 `campusIds` 必填非空。教师 `classIds`、家长 `studentIds` 必须在操作者可管理范围。
- `PUT /users/{id}/access` `{campusIds?:[],classIds?:[],studentIds?:[]}` → 用户。SUPER_ADMIN配置校区ADMIN的campusIds；校区ADMIN只能为完全在其范围内的教师/家长调整对应班级/学生，不能扩大权限或接管跨校区账号。
- `POST /classes`、`POST /courses` 新增 `campusId`，单一可管理校区可兼容省略；班级/课程/学生/排课/账户查询附带 `campusId,campusName` 方便汇总。
- `GET /audit-logs` 校区管理员只读本校区日志，总管理员可看全局；日志保存操作者ID和校区归属。

## 设置

机构级设置只能总管理员改；校区管理员不得通过设置修改其他校区信息或全机构积分规则。校区独立配置使用 `campus_setting`（若实现），选择校区时规则按所在校区真实生效。至少明确禁用校区管理员的全局设置写入，允许其查看自己校区与账户权限。

## 页面

管理Web：侧栏/顶栏真实校区选择，SUPER_ADMIN有全部校区；账号设置可建校区管理员并多选授权校区、编辑授权；校区管理可建校区、查看该校区教师学生统计；老师/学生列表显示校区，按当前上下文过滤；切换校区清理旧页查询/弹窗，重新加载。

微信小程序：SUPER_ADMIN拥有原ADMIN操作入口；ADMIN名称显示校区校长，数据依后端范围；两目录需定向同步，不能覆盖不同环境配置/RSA登录更改。

小程序管理员首页显示校区运营概览，老板与校长均可切换自己的可访问校区；“今日到校”“老师签到”和近七日出勤可携带所选日期进入明细。老师本人可在“我的打卡”登记当天到校，老板和校长查看签到名单与时间。切换校区、账号或收到授权变更后清空旧选择、表单及附件，丢弃旧范围的异步响应。

“校区与权限”展示可访问校区及师生、班级统计。老板可在小程序为已有校长账号多选管理校区，也可撤销全部校区权限；校长只读本人授权，不得自行扩权。该授权页始终处理完整授权范围，避免当前校区筛选覆盖其他校区权限；校长账号创建沿用 Web 后台。

## 验收重点

两个校区各自学生、老师、课程、作业、账户等；总管理员可看全量/单校区；校长A不能通过列表、手工ID、header、批量接口、附件、续费确认、冲正、补扣、账号授权访问B；家长和老师旧授权仍生效；修改授权后已有会话立即按新权限执行；迁移保留现有上传语音与课时账目；现有RSA密码传输保持。
