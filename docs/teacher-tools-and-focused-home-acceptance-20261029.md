# 教师工具与精简首页验收

日期：2026-10-29。范围：小程序、Web/App 页面和后端 V17。首页围绕当日作业、签到签退、家校消息；原有积分、课程、订餐、班级日报等保留在“全部应用”，不删除业务数据。

## 页面与入口

| 使用者 | 首页默认内容 | 二级功能 |
| --- | --- | --- |
| 老师 | 班级与日期、学生名单、每名孩子作业完成数及优先处理状态、签到签退时间、拍照签到或签退、作业消息页签 | 批量处理按需展开；拍照录题、错题打印、课时增加、续费、积分奖品、班级日报从全部应用进入 |
| 家长 | 孩子选择、当日各项作业及批改状态、到离校时间、老师留言预览 | 到离校照片与通知、接送授权、小结及反馈、课程订餐、成长记录；低余额仅显示一条预警入口 |
| 校长与老板 | 保留授权校区运营首页 | 配置固定积分、奖品库存图片、自动奖励规则，查看班级与家长意向 |

底部导航收拢为首页、作业、消息、全部。首页不展开积分/体能统计、完整成长时间轴或多组功能宫格；批量处理默认关闭。接送异常和需要关注的事项继续明显提示。未到校、已请假、未记录具体时刻均如实显示；无作业不算已完成。

参考：用户提供的 https://www.wenqiyousi.com/ 及其官网公开展示图 `pic_index_report.png`、`pic_index_realtime.png`、`pic_index_wrong.png`。借鉴按作业、通知、小结组织信息的方式，保持本项目现有柔和圆角组件。未复制品牌、学生照片或素材进入应用。

## 教师工具行为

- 拍照签到/签退：选定孩子后拍照或选图，照片作为记录凭证；不做人脸识别。仅服务器当天，老师限自己班级。签退仍须有效接送授权及现场核验，不会绕过异常拦截。已签到或签退重试不重复创建考勤/消息。
- 站内通知：到校、离校各给当前绑定家长生成记录，可查看照片并标记已读；更换绑定后的账号不能读取旧孩子信息。微信状态明确为 `NOT_CONFIGURED`，未发送微信订阅推送。
- 增加课时：老师可为授权班级孩子选择同校区已有课程，增加独立课时并注明原因；可自动创建该课程报名与账户。同请求号重试不重复加课时，记 `TEACHER_GRANT`，不表示已收款。
- 拍照录题：上传图片 → 手工校对题干 → 确认保存为错题或作业。OCR尚未配置，返回空识别结果和手工确认提示；不生成虚假识别文字。作业保存为待批改，可绑定既有作业或新建当日作业；同请求号保存防重。
- 错题本：照片、题干至少一项即可保存，知识点与错误原因可后补；可按孩子、科目生成1–100题的私有PDF，含中文题干、照片、订正区和页码，下载仍需短效票据与媒体授权。
- 积分：校长/老板维护校区固定奖励，老师按预设发放，服务端决定分值。原有作业完成自动奖励保留；日小结经审核并发布时默认奖励2分，生成草稿不奖励，重复发布不重复奖励。管理员可在设置中调整事件奖励。
- 奖品：配置名称、兑换积分、库存、独立封面图片；老师为孩子兑换并发放，原子扣减积分与库存，家长查看记录。可保存最多6张兑换照片。学生私有照片不能作为全校区可见奖品封面。
