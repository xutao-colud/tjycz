# 拍照识题首版验收

日期：2026-10-31。范围：微信小程序、Java后端V18、本机独立PaddleOCR服务。Web/App保留原手工录题入口，本次没有发布客户端或部署外部服务器。

## 已实现

老师从“今日班级”每个孩子的“拍照识题”，或“全部应用 → 拍照识题”进入。先选孩子、科目，再拍照或选一张图片。后台持久化扫描任务，显示排队/识别、待校对或失败，离开页面后可以从扫描记录继续。

标准页叠加题框，点击题框与题号联动。默认不勾选；老师可校对文字、拖动/缩放范围、补框、上下拆分、合并下一题或移除候选。阅读材料随对应小问保留。已入库题目不能在扫描记录中覆盖或删除。冲突时可明确放弃未保存修改并重新载入；普通返回预览不丢失草稿。

仅明确选择的候选生成独立错题，附题目裁图，不给每题重复附整页。保存校对后再入库，重试保持同一任务/候选映射，部分失败只保留失败项勾选。错题本可继续复习、生成PDF；扫描题以裁图打印，保留图形、公式和原笔迹，仅移除纯白外边，不重复打印OCR文字。打印按来源页面比例缩放，避免小裁图被放大成整页大字。

后端每次查询、调整、裁图与入库校验老师班级/校长校区及学生服务、媒体授权；后台任务执行前后重新验证原操作会话和授权。家长通过既有错题接口查看绑定孩子已入库记录。文件继续使用短期私有票据，预览前刷新，任务接口不返回后台会话哈希。

## 未验收与首版限制

微信开发者工具服务端口关闭，尚未完成IDE自动运行、iOS/安卓真机拍照与拖框验收。此前手机网络问题和音频实际听感不属于本轮通过结果。

当前为单页专用OCR与规则分题，没有自动批改、答案讲解、跨页关联、手写擦除、复杂公式文字转换、透视/弯曲展平或大模型补扫。没有独立真实练习册验收集，不承诺90%准确率或生产并发性能。低质量照片、复杂手写及误分题需重拍或老师校对，主流程保留手工录题。
