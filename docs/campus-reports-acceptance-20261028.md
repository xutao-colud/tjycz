# 校区总结与班级点评验收 · 2026-10-28

校长可以在“校区总结”按日期记录授权校区的整体情况、重点跟进与后续安排，并查看每个班级的情况、老师日报和已有点评。老板可以选择全部授权校区。入口位于校长/老板工作台及全部功能，小程序、App和后台均已接入。

## 保存与权限

校区概况自动汇总学生到校、请假、老师签到、作业完成及班级数量。每校区每天一份总结，正文最多6000字，重点跟进与后续安排分别最多2000字。记录人和时间由服务端确定。重复保存相同内容不新增版本，其他人更新后旧版本提交返回409并保留界面编辑内容。未来日期不能保存事实总结。

班级点评为单独记录，校长和老板可对授权校区的班级追加点评，单条最多2000字，保留点评人、角色与时间。即使老师还没有填写当日日报，也可以根据现场情况点评。点评不会改动老师日报的正文和版本；对应班级老师可在“班级日报 → 校长点评”查看，教师不能提交校长点评。点评使用请求标识防止重试重复创建，相同标识换内容或换日期会拒绝。

服务端限制校长的校区及其班级范围，`X-Campus-Id`仍可继续缩小范围。教师和家长不能访问校区总结；家长不能读取整班日报或点评。教师只可读取当前授权班级的点评，撤销班级授权后立即拒绝访问。校长和老板原有的班级日报维护权限仍然有效，新增点评使用独立存储与操作入口。

## 接口与迁移

- `GET /api/campus-reports?date=&campusId=`：返回授权校区、当前校区、概况、总结和班级卡片。
- `PUT /api/campus-reports/{campusId}?date=`：保存`{content,followUp,nextPlan,expectedVersion}`。
- `POST /api/class-reports/{classId}/comments?date=`：追加`{text,requestId}`。
- 原班级日报查询增加`comments`数组，原正文保存接口继续保留。

V15新增`campus_daily_report`与`class_report_comment`，不覆盖原有日报。复用原班级概况计算，老师出勤按所选校区统计。保存与点评写入校区审计，仅记录关联ID、日期，不把正文写入审计详情。点评为追加记录，当前未提供编辑/删除或推送通知流程。
