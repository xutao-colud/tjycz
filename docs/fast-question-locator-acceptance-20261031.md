# 快速框题与识别耗时验收（2026-10-31）

当前小程序默认只定位题号、附加题等分题标记，按边界保存整题裁图。题干正文、图表、公式使用图片，识别结果不再转写孩子的整页手写答案。文字补充为选填；空文字也能将选中题目加入错题库，图片仍可打印。原图和裁图保留拍照时的笔迹，本版不执行擦除。

## 本页同机对比

使用用户上一轮提供的同一张原始练习页，分别调用修改前、修改后的本机OCR HTTP接口各3次，未向日常业务数据库写入测试扫描任务。

| 范围 | 修改前 | 修改后 |
| --- | --- | --- |
| 3次接口耗时（秒） | 8.298、7.503、8.546 | 3.923、2.748、2.858 |
| 中位耗时 | 8.298秒 | 2.858秒 |
| 分题 | 第3题、第4题、附加题 | 第3题、第4题、附加题 |
| 题干文字 | 混入手写答案的整页转写 | 默认留空，使用原图裁题 |
| 标准页尺寸 | 1023×1352 | 1023×1352 |

本页中位耗时减少约66%。这是本机单页样本的OCR内部接口测量，包含请求和结果返回，不含手机上传、业务任务排队及小程序轮询等待；首轮模型推理较慢，不能据此承诺其他设备、照片或负载下的耗时。

## 实现

- 保留原有方向校正、版面检测、文字检测和文字识别模型，不升级依赖或下载新模型。按模块调用，跳过完整文档解析及全文转写。
- 检测最长边限制1280像素；只读取常规字高、列首附近候选行的短前缀，用于识别题号及标题。只有分题标记参与分组，不将答案转写为题干文字。
- 标准页仍保留原有最长边2600像素上限。题框、预览、裁图和打印坐标保持一致；大题小问和配图保留在同一题；明确阅读标题前的材料保留为共享图片。
- 小程序说明改为快速框题，选填文字为空时缩小输入框。旧任务和已入库题目保持原状；“原图重识别”创建新任务。
- 权限、监护人授权、内部服务凭据、图像大小限制、单任务推理锁和手工框题降级沿用原边界。

模块调用依据：[PaddleOCR文字检测](https://www.paddleocr.ai/main/en/version3.x/module_usage/text_detection.html)、[文字识别](https://www.paddleocr.ai/main/en/version3.x/module_usage/text_recognition.html)及已安装的3.7.0源码；本次耗时结论来自本地实测。

## 验收

- OCR规则和服务测试15项通过，包括短前缀读取、不返回答案文字、未知页面手工框题、共享阅读图片、附加题及模型float32坐标的JSON序列化。
- 后端QuestionScanIntegrationTest 10项通过，包含无题干文字时的裁图入库、附加题命名，以及原有打印与权限检查。
- 小程序20项扫描检查、结构检查通过；微信自带wcc/wcsc编译35个WXML、37个WXSS通过。
- 微信开发目录定向同步3个文件，并在目标目录通过结构检查与20项扫描检查；未改project配置、定位说明或网络地址。
- OCR服务已正常重启，本地18080仍健康；内部凭据、无效图片请求检查通过。检查期间的429来自识别性能测量占用单任务锁，测量结束后按顺序复查通过。

微信真机尚未复测。特殊题号字号、缩进、复杂多栏或无明确标题的阅读材料仍需老师核对范围；不能可靠定位时使用补框/调框，不自动编造题干。真实图片、文字和服务凭据只保留在本机私有运行目录，未发布公开预览。
