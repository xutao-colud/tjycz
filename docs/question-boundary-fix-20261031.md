# 拍照识题分题修复验收（2026-10-31）

用户提供的同一张练习页，修复前只有一个候选“3(2)”，第4题和附加题被混入其范围。本次在本机专用OCR上重放原始上传图片，修复后返回 **第3题、第4题、附加题**，每题一个连续题框；第3题保留(1)、(2)和配图，第4题与附加题互不混入，页脚不计入题目。

## 改动

- 分题以顶层题号为单位，小问、条件、选项及配图保留在所属题目中；附加题作为单独边界。
- 对题号与正文数字连读的情况，必须同时满足相邻题号连续、左侧对齐和版面标题检测才恢复题号，并提示老师复核，避免直接将普通小数当题号。
- 小程序“原图重识别”复用原图创建新任务，不覆盖旧记录的校对、题框或入库结果；仍由老师选择后才入库。
- 附加题在选择卡片、导入的错题标题与图片文件名中直接使用“附加题”。

## 使用与限制
