# 晚辅智管 · 微信原生小程序

使用原生 JavaScript / WXML / WXSS，12 个页面，无 npm 依赖、无 TypeScript 或构建步骤。青绿界面通过顶部“全部功能”导航，详情使用微信返回导航。所有业务数据及成功结果来自真实后端 API，不内置假成功数据。

## 微信开发者工具导入

1. 启动项目后端的 local 环境，确认 `http://localhost:18080/api/health` 返回 `status: UP`。本项目 local 端口为 **18080**，避免占用其他项目的 8080；生产后端默认 8080，需按实际部署配置地址。
2. 微信开发者工具 → 导入项目 → 选择本 `miniprogram/` 目录（不要选择项目根目录）。开发模式选择“小程序”。
3. 本地导入可使用“测试号”或自己的 AppID；仓库的 `project.config.json` 使用 `touristappid`。手机预览、正式上传需要自己的小程序 AppID 与开发者权限。
4. 在“详情 → 本地设置”勾选“不校验合法域名、web-view（业务域名）、TLS 版本以及 HTTPS 证书”，仅用于 local 联调。默认配置 `urlCheck: false`，不应据此跳过正式环境域名配置。
5. 点击“编译”，进入登录页面。无需“构建 npm”。基础库使用 3.7.1 或更新版本，需支持 `wx.chooseMedia`、`wx.previewMedia`。
6. 正式发布前将 `project.config.json` 的 `appid` 改为自己的 AppID，将 `setting.urlCheck` 改为 `true`，在微信公众平台配置 request、uploadFile、downloadFile 的 HTTPS 合法域名。

## 服务地址、文件与录音

地址统一在 `utils/config.js` 配置：

```js
apiBase: 'http://localhost:18080/api'
```

微信开发者工具中的 localhost 指本机；真机中的 localhost 指手机本身。局域网预览改为电脑 IP，例如 `http://192.168.1.10:18080/api`，并确保手机与电脑在同一网络、后端监听局域网地址。正式环境使用已配置合法域名的 HTTPS 地址，例如 `https://api.example.com/api`。生产后端内部默认端口 8080，与小程序公开 HTTPS 地址无须相同。

`wx.chooseMedia` 选择图片/拍照/最多60秒短视频，`wx.uploadFile` 以 multipart 字段 `file` 上传 `/files`。单文件最多 20MB，每次业务表单最多 6 个附件。上传成功只生成文件，不代表业务提交；“保存附件”“提交订正”“创建任务”等按钮会将文件 ID 关联到对应业务。文件 URL 保留后端返回的当前会话 token；`/api/files/...` 相对地址只拼接域名，避免重复 `/api`。不要打印或分享带 token 的文件链接。读取权限仍由后端验证。

口头作业提供 `wx.getRecorderManager()` MP3 录音，最长60秒，停止后通过相同 `/files` 接口上传。页面明确显示录音状态与秒数，录音/上传时禁止提交；拒绝麦克风权限后可重试或打开设置。离开/卸载页面会停止并取消未完成录音，已成功上传的附件需提交关联。`app.json` 已提供 `scope.record` 用途说明。已有图片、音频、视频附件可预览，音频播放在组件移除时停止。

后端支持 PNG/JPG/GIF/WEBP、MP3/WAV/OGG、MP4/WEBM；不支持 AMR。相机若返回不支持的格式，界面保留真实上传错误，不宣称上传完成。

## 登录与角色

- **机构账号登录**：调用 `POST /auth/login {username,password}`，角色完全由后端会话决定，生产关闭 demo 后仍可使用。账号请由机构管理员提供。
- **本地演示入口**：独立标注“仅 local 环境”，调用 `POST /auth/demo`。可选择教师、家长、管理员。教师只见后端授予的班级，家长只见绑定孩子；没有硬编码前端学生名单或权限映射。生产未开启会显示真实接口错误。
- **真实微信登录未完成**：当前后端没有 `wx.login` code 换取会话接口，需要后端接入 AppID、AppSecret、微信身份绑定；界面已明确说明，不伪造微信授权。
- 登录后保存 token，所有业务请求发送 `Authorization: Bearer ...`；HTTP 401 清除会话并返回登录页，403 保留无权限错误。
- 顶部“全部功能 → 切换角色 / 登录账号”可用另一真实账号登录，或在 local 演示中切换身份。新会话会清除旧学生选择。后端学生权限是最终依据。

## 页面与可操作流程

| 页面 | 教师 / 管理员 | 家长 |
| --- | --- | --- |
| 工作台 | 日期统计、学科进度、出勤趋势、最近动态与工作入口 | 绑定孩子概况、作业进度、动态与家校入口 |
| 学生名册 | 班级/关键词筛选、多选后进入考勤/作业/日报 | 已绑定孩子查询、选择 |
| 人工考勤 | 选择日期与授权学生，批量签到/签退，逐人展示结果 | 无教师入口 |
| 作业列表 | 日期/学生/学科/状态筛选，创建书面或口头任务，关联图片、视频或录音 | 查看自己孩子的任务 |
| 作业详情 | 进入进行中/待批改、正确率与评语、完成或退回订正、代交订正 | 上传书写/口头作业，提交待批改，需订正时提交待复核 |
| 错题成长本 | 选择学生，拍照或文本录入，学科与状态筛选 | 为绑定孩子录入与查看错题 |
| 订正与复习 | 提交订正、复核通过/退回、到期确认复习 | 文字与照片订正、查看反馈和复习进度 |
| 体能记录 | 日期/学生筛选、按项目批量打卡 | 查看孩子运动记录 |
| 成长积分 | 查看流水、按原因调整，失败重试保留同次幂等编号 | 查看余额、实际机构积分规则与流水 |
| 课程课时 | 各课程独立余额与流水、续费记录、重试待处理消课 | 查看孩子各课程账户、余额、课时和续费流水 |
| 每日小结 | 选择日期/学生生成草稿、编辑教师评语、发布、阅读反馈 | 阅读已发布快照、1–5分评分和文字反馈 |
| 登录与角色 | 机构账号、本地演示、已有会话退出/继续 | 同左 |

所有页面都有加载、网络错误重试与空数据状态；操作有按钮互斥、异常提示。所有状态转换、绑定范围、积分、签退消课、幂等与文件可见性由后端验证。业务状态显示中文，日报正文中的后端状态码也转为中文。

错题标题最多300字，订正必须填写简述，可同时上传图片；批改正确率为0至100整数。复习任务由后端按错题创建后第1/3/7天生成，小程序到期后只向教师展示完成按钮。签到签退为人工操作；不包含人脸识别。

日报发布只表明站内可读。通知状态为 `NOT_CONFIGURED` 时明确显示“消息服务未配置”，不声称微信推送成功。续费办理、在线支付、课程报名配置和学生账号管理不在本小程序页面范围，课时只读结果与教师结算重试均来自后端。

## 本地校验与联调

在已安装 Node.js 18+ 的环境执行：

```sh
node /绝对路径/miniprogram/scripts/validate.js
node /绝对路径/miniprogram/scripts/check-runtime.js
```

第一条检查全部 JSON、JS 语法、12个路由四件套、共享组件声明、页面跳转、相对 require、WXML 标签和事件绑定。第二条在微信 API 测试替身下验证请求头、401/403、文件地址、页面错误恢复和录音生命周期等关键逻辑，不依赖后端。

以下命令仅允许 local 演示后端执行，会创建标题带“小程序接口联调”的业务记录，并使用当前上海业务日期，覆盖真实接口与页面数据加载；不要对生产数据执行：

```sh
node /绝对路径/miniprogram/scripts/check-api.js
```

检查脚本使用小程序实际 `utils/api.js`，其 wx 网络测试替身将请求发送至真实后端；可验证账号权限、作业、文件读写、错题、体能、积分幂等、考勤、日报与页面数据加载。接口检查通过不等同微信渲染、相机、麦克风与真机权限通过，后者需在微信开发者工具和真机验收。

微信开发者工具 CLI 若提示服务端口关闭，可手动进入“设置 → 安全设置 → 服务端口”开启后再使用。未开启不会影响手动导入。本实现未更改工具安全设置。
