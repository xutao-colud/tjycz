## 服务地址、文件与录音

地址统一在 `utils/config.js` 配置：

```js
apiBase: 'http://8.163.74.71/api'
```

微信开发者工具中的 localhost 指本机；真机中的 localhost 指手机本身。局域网预览改为电脑 IP，例如 `http://192.168.1.10:18080/api`，并确保手机与电脑在同一网络、后端监听局域网地址。正式环境使用已配置合法域名的 HTTPS 地址，例如 `https://api.example.com/api`。生产后端内部默认端口 8080，与小程序公开 HTTPS 地址无须相同。

`wx.chooseMedia` 选择图片/拍照/最多60秒短视频，`wx.uploadFile` 以 multipart 字段 `file` 上传 `/files`。单文件最多 20MB，每次业务表单最多 6 个附件。上传成功只生成文件，不代表业务提交；“保存附件”“提交订正”“创建任务”等按钮会将文件 ID 关联到对应业务。文件 URL 保留后端返回的当前会话 token；`/api/files/...` 相对地址只拼接域名，避免重复 `/api`。不要打印或分享带 token 的文件链接。读取权限仍由后端验证。

口头作业提供 `wx.getRecorderManager()` MP3 录音，最长60秒，停止后通过相同 `/files` 接口上传。页面明确显示录音状态与秒数，录音/上传时禁止提交；拒绝麦克风权限后可重试或打开设置。离开/卸载页面会停止并取消未完成录音，已成功上传的附件需提交关联。`app.json` 已提供 `scope.record` 用途说明。已有图片、音频、视频附件可预览，音频播放在组件移除时停止。

后端支持 PNG/JPG/GIF/WEBP、MP3/WAV/OGG、MP4/WEBM；不支持 AMR。相机若返回不支持的格式，界面保留真实上传错误，不宣称上传完成。

## 后端连接与密码加密

当前接口为电脑局域网地址 `http://8.163.74.71/api`，开发者工具和同网手机共用该配置；两个小程序目录已同步。只调试小程序时，执行 `bash /Users/xutao/Documents/错题小程序/scripts/backend-local.sh start` 独立启动后端；`status` 可查看状态，`restart --build` 可重建更新。服务监听 `0.0.0.0:18080`，日志位于项目 `.run/backend.log`。手机与电脑需在同一局域网，电脑 IP 变化后更新 `utils/config.js`。可在手机浏览器打开 `http://8.163.74.71/api/health` 检查连通性；微信局域网调试需关闭合法域名校验并视需要开启真机调试。正式环境使用 HTTPS 合法域名。

`utils/api.js` 在每次账号登录前获取 `/auth/challenge?purpose=LOGIN`，用 RSA-2048 OAEP-SHA256/MGF1-SHA256 加密密码，只发送 `challengeId` 和 `encryptedPassword`，不发送明文 `password`。challenge 60 秒有效且只能消费一次，重试会重新获取；服务端拒绝明文、过期、篡改及重放。加密依赖为 `utils/vendor/forge.js`（node-forge 1.4.1），OAEP seed 来自 `wx.getRandomValues`，缺失时提示更新微信，不退回弱随机数或明文。

本地 HTTP 仍只适合开发，应用层 RSA 不保护公钥分发及返回的会话令牌，正式环境必须使用 HTTPS。管理 Web 的登录和创建账号同步采用加密协议，后端数据库仍用 BCrypt 存储密码。

验证：后端 29 项测试、Web 构建、`scripts/check-password.js` 的微信/Node互通和无明文断言通过；真实 18080 的三角色加密登录通过，明文和重放均被拒绝；隔离数据库下 80 次教学业务接口回归通过。

## 整页拍照识题（V18）

分题以顶层题号为单位：同一大题的小问、条件和图示放在一起，“附加题”单独成题。识别完成后可点击“原图重识别”创建新的扫描记录，复用原始照片并保留旧记录的校对与入库结果；不会覆盖已有题目。附加题在选择卡片、错题标题和裁图文件名中直接显示其名称。

拍照识题自动提取常规印刷体的题干、标题、选项和表格文字，并按题号分题；标题与题干自动填入编辑栏，可直接校对。校对后的标题与正文随所选题目一起保存到错题库，裁图文件仍按题号命名。通过版面和行高过滤明显手写区域及答题演算，不保证识别所有混写内容，需对照原图核对。图表和公式同时保留裁图。旧扫描记录不会自动更新，点击“原图重识别”使用新规则。原图和打印裁图仍保留拍照时的笔迹，不自动擦除。

扫描任务提交后立即处理，小程序前3秒以250毫秒间隔取回结果，随后放缓为1秒；隐藏或退出页面停止查询，重新打开可继续查看。完整印刷标题、题干与图表文字仍自动填入。当前轻量模型及本机端到端耗时验收见`../docs/scan-speed-acceptance-20261031.md`；3秒测试范围不包含用户拍照、手机屏幕绘制或网络拥塞。
